Asistente de razonamiento (modo demostración)

Esta primera versión utiliza reglas sencillas en el dispositivo. No consulta internet ni genera recomendaciones clínicas personalizadas. Las sugerencias deben verificarse con fuentes autorizadas y con el docente.

¿Cómo activar IA real más adelante?

La integración real requiere un servicio de IA y una pequeña API segura en un servidor. No pegues una clave secreta de API dentro de esta aplicación, porque otros usuarios podrían extraerla. En el prototipo actual no se realizan llamadas externas ni se generan costos por IA.
